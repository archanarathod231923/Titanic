# Titanic

## 🚢 Titanic Dataset — Data Preprocessing

A beginner-friendly Data Science project focused on exploring and preprocessing the Titanic dataset using Python and popular data analysis libraries.

## 📌 Project Overview

The Titanic dataset contains information about passengers aboard the Titanic, including passenger class, age, gender, fare, and survival status.

The goal of this project is to understand the dataset, explore data quality, handle missing values, and learn important data preprocessing techniques used in Machine Learning.

## 🎯 Project Objectives

* Understand the structure of the Titanic dataset.
* Perform Exploratory Data Analysis (EDA).
* Identify and handle missing values.
* Apply missing-value imputation techniques.
* Understand feature scaling methods.
* Explore outlier detection techniques.
* Learn how Scikit-learn pipelines help organize preprocessing steps.

## 📂 Dataset

**Dataset Name:** Titanic Dataset

**Dataset Source:** [Titanic Dataset — DataScienceDojo GitHub](https://github.com/datasciencedojo/datasets/blob/master/titanic.csv)

The dataset includes passenger information such as:

* Passenger ID
* Passenger class
* Name
* Sex
* Age
* Number of siblings or spouses aboard
* Number of parents or children aboard
* Ticket
* Fare
* Cabin
* Embarked port
* Survival status

You can view or download the dataset from the source link above.

## 📚 Project Workflow

### 1. Data Loading and Understanding

* Load the dataset using Pandas.
* Inspect the first few rows.
* Check the dataset's shape, columns, and data types.

### 2. Exploratory Data Analysis (EDA)

* Examine the distribution of data.
* Identify missing values.
* Use visualizations to understand important patterns.

### 3. Missing Value Handling

* Identify columns containing missing values.
* Explore imputation techniques to handle missing data.

### 4. Feature Scaling

* Understand **Normalization** and **Standardization**.
* Compare how scaling methods transform numerical features.

### 5. Outlier Detection

* Explore the Interquartile Range (IQR) method.
* Understand Z-score-based outlier detection.

### 6. Scikit-learn Pipelines

* Learn how preprocessing steps can be organized into pipelines.
* Understand how pipelines help maintain a consistent preprocessing workflow.
